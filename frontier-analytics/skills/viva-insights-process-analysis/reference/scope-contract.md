# Scope and reporting contract

Start with the business question. An annual audit, close or planning cycle can
have stages, title conventions and owners that are absent from the export.
Do not reconstruct the full process from collaboration records.

## Minimum contract

| Field | Record |
|---|---|
| Question and audience | Description, monitoring or a proposed causal question; intended discussion/decision |
| Sources | Local files and fingerprints, export purpose, query configuration, grain and keys |
| Measurements | Raw headers, metric definition, units, denominator and required observations |
| Coverage | Verified configured start/end, ingestion limitations, separate complete month/week cutoffs |
| Process phases | Dates and cycle labels, including the calendar year versus the year being planned/audited |
| Scope rules | Version, status, approver, category expressions, aliases, languages, exclusions and annual gates |
| Event decisions | Exact occurrence key, reason, decision version, precedence and pending disposition |
| Comparisons | Matched dates/phases, full-cycle versus cycle-to-date, cohort and organisational lens |
| Publication | Distinct-person privacy basis, any separate event stability floor, complementary protection |
| Evidence and refresh | Aggregate outputs, assertions, prior approved baseline, output location and permissions |

Unknown fields stay unknown. A missing intervention start date blocks an
intervention verdict, not a clearly labelled description of observed meetings.
Missing subjects can block topical classification without blocking an agreed
structural MQ analysis.

## Two working states

**Discovery:** explore broad candidates, language coverage and alternative rules.
Use bounded, stratified local review packs. Report added/removed event membership
and hours by year, with worked inclusions and exclusions. These are diagnostic
scenarios. Do not quietly replace an approved definition.

**Approved reporting:** persist the chosen rules, tests, coverage evidence and
comparison contract. Generate aggregates and publications from that version.
If the definition changes later, create a new version and a reconciled bridge.
Never rewrite a frozen reference to hide a difference.

## Coverage is a source contract

Confirm configured grain and source bounds. Compare dense full-query diagnostics
with saved configuration or explicit source-owner confirmation. Low activity
and the last observed event cannot prove either completeness or a gap.

Keep partial observations available for review. A complete-month cache that has
already discarded boundary events cannot answer a later partial-month question
merely by changing a report's dates. Choose the appropriate prepared evidence.

For a complete configured interval with no process matches, a zero process count
is valid. Out-of-scope dates, partial/unavailable periods, unknown capture and
privacy-withheld values remain distinct. Follow the core policy rather than
blanket zero-filling or blanket withholding.

## History and source revisions

Compare vintages on shared keys before stitching. Check membership, hours,
quality fields, definitions and organisational revisions. The core Meeting Query
reference describes one optional reconstruction policy. It is not a universal
preference for older rows. A current snapshot and a historical reconstruction
can legitimately choose different policies.

Person Query history uses its own key and compatibility checks. A full newer-row
winner retains observed zeros and blank attributes. Backfilling older values
requires explicit approval and field-level provenance. Do not blend incompatible
metric definitions to obtain a longer history.
